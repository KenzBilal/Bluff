# Contributing to Bluff

First off, thank you for considering contributing to Bluff! It's people like you that make Bluff a great tool for everyone.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/your-username/bluff.git`
3. **Open the project** in Android Studio (Giraffe or newer).

## Workflow

1. Create a branch for your feature or bug fix:
   `git checkout -b feature/your-feature-name`
2. Write your code and tests. We use **Jetpack Compose** and **Clean Architecture**. Please try to follow the existing patterns and structure.
3. Run the linter to ensure code quality:
   `./gradlew lint`
4. Commit your changes using descriptive commit messages.
5. Push your branch and open a Pull Request against the `main` branch.

## Pull Request Guidelines

- Ensure your code compiles without warnings.
- If you're adding a feature, please include relevant tests or update the README.
- Be prepared to discuss your changes and make revisions based on feedback.

## Reporting Bugs / Requesting Features

Please use the GitHub Issue Tracker to report bugs or request features. When reporting a bug, include:
- A clear, descriptive title.
- Steps to reproduce the issue.
- Expected behavior vs actual behavior.
- Device information and Android version.
